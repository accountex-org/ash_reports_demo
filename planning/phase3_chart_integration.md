# Phase 3: Chart Integration

**Duration**: 1-2 weeks
**Goal**: Integrate AshReports chart generation system with demo UI
**Prerequisites**: Phase 1 and Phase 2 completed

## Overview

Phase 3 integrates the AshReports chart generation system (`AshReports.Charts`) into the demo UI, providing interactive chart displays, configuration forms, and integration with report data. This phase showcases all 5 chart types (bar, line, pie, area, scatter) with theming support and caching optimization.

**Key Deliverable**: Full chart integration with gallery, preview, and report-embedded charts.

  defmodule AshReportsDemoWeb.Reports.ChartDataExtractor do

- [ ] Extract chart data from report results
  ```elixir
  def extract(report_result, chart_config) do
    records = report_result.records

    case chart_config.data_source do
      :records ->
        transform_records_to_chart_data(records, chart_config)

      {:field, field_name} ->
        extract_field_data(records, field_name)

      static_data when is_list(static_data) ->
        static_data
    end
  end
  ```

- [ ] Transform report records to chart format
  ```elixir
  defp transform_records_to_chart_data(records, config) do
    Enum.map(records, fn record ->
      %{
        category: Map.get(record, config.category_field),
        value: Map.get(record, config.value_field)
      }
    end)
  end
  ```

- [ ] Handle different data structures
  - Flat records → chart data
  - Grouped data → multi-series
  - Aggregated data → summary charts
  - Time-series → line/area charts

- [ ] Aggregation helpers for chart data
  ```elixir
  def aggregate_for_chart(records, group_by, value_field) do
    records
    |> Enum.group_by(&Map.get(&1, group_by))
    |> Enum.map(fn {category, group} ->
      total = Enum.reduce(group, 0, fn record, acc ->
        acc + (Map.get(record, value_field) || 0)
      end)

      %{category: category, value: total}
    end)
  end
  ```

- [ ] Support for time-series conversion
  ```elixir
  def convert_to_time_series(records, date_field, value_field) do
    records
    |> Enum.sort_by(&Map.get(&1, date_field), Date)
    |> Enum.map(fn record ->
      %{
        date: Map.get(record, date_field),
        value: Map.get(record, value_field)
      }
    end)
  end
  ```

- [ ] Create `ChartCache` wrapper module
  ```elixir
  defmodule AshReportsDemoWeb.Reports.ChartCache do
    alias AshReports.Charts.Cache

    def get_or_generate(chart_type, data, config, opts \\ [])
    def clear_for_report(report_name)
    def get_statistics()
  end
  ```

- [ ] Leverage `AshReports.Charts.Cache` ETS cache
  ```elixir
  def get_or_generate(chart_type, data, config, opts) do
    cache_key = generate_cache_key(chart_type, data, config)

    case Cache.get_decompressed(cache_key) do
      {:ok, cached_svg} ->
        {:ok, cached_svg}

      {:error, :not_found} ->
        case AshReports.Charts.generate(chart_type, data, config) do
          {:ok, svg} ->
            ttl = Keyword.get(opts, :ttl, :timer.minutes(5))
            Cache.put_compressed(cache_key, svg, ttl: ttl)
            {:ok, svg}

          error ->
            error
        end
    end
  end
  ```

- [ ] Cache chart SVGs by configuration hash
  ```elixir
  defp generate_cache_key(chart_type, data, config) do
    content = :erlang.term_to_binary({chart_type, data, config})
    :crypto.hash(:sha256, content) |> Base.encode16(case: :lower)
  end
  ```

- [ ] TTL management (default 5 minutes)
  - Configurable per chart
  - Auto-refresh for live data
  - Invalidation triggers

- [ ] Cache statistics display

  def get_statistics do
    stats = Cache.get_stats()
